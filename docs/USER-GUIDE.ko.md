# Whiplash 사용 설명서

버전 0.2 · macOS 13 이상 · Apple Silicon / Intel

Whiplash는 Mac에서 실행 중인 AI 코딩 에이전트(Claude Code, Codex, Cursor, Gemini CLI 등)를 모니터링하고 제어하는 데스크톱 유틸리티입니다. 각 에이전트 세션을 화면 위의 캐릭터로 표시하여 현재 작업, 대기 상태, 자원 사용량을 한눈에 파악할 수 있으며, 세션에 지시를 보내거나 작업을 재개시킬 수 있습니다.

---

## 1. 시스템 요구 사항

| 항목 | 요구 사항 |
|---|---|
| 운영체제 | macOS 13 Ventura 이상 · Windows 10/11과 Linux(x64)는 2.3절의 별도 판 |
| 프로세서 | Apple Silicon 또는 Intel |
| 지원 에이전트 | Claude Code(터미널·Claude 앱), Codex CLI/앱, Cursor, Gemini CLI, Antigravity, 기타(opencode, aider, goose 등) |
| 세션 정보 표시 | Claude Code 2.1 이상(세션 파일 `~/.claude/sessions` 생성 버전) |

세션 제목, 현재 작업, 대기 상태, 지시 보내기, 자동 채찍은 Claude Code 세션에서만 제공됩니다. 그 외 에이전트는 프로세스 단위의 CPU·메모리 정보만 표시됩니다.

## 2. 설치

### 2.1 직접 배포판 (전체 기능)

1. 배포된 `Whiplash.app`을 `/Applications`로 복사합니다.
2. 처음 실행 시 macOS가 확인을 요청하면 **열기**를 선택합니다. (Developer ID로 서명·공증된 빌드는 추가 확인 없이 실행됩니다.)
3. 메뉴 막대 오른쪽에 Whiplash 아이콘이 나타나고 모니터링이 시작됩니다.

소스에서 빌드하려면 Xcode Command Line Tools가 필요합니다.

```bash
xcode-select --install
./build.sh --install
```

### 2.2 Mac App Store 판 (기능 제한)

App Store 판은 Apple의 앱 샌드박스 안에서 동작합니다. 다음 기능이 제한됩니다.

| 기능 | 직접 배포판 | App Store 판 |
|---|---|---|
| 세션 모니터링, 상태 표시, 자원 사용량 | 제공 | 제공 (홈 폴더 접근 1회 허용 필요) |
| 화면 돌아다니기, 우리, 단축키, 메뉴 | 제공 | 제공 |
| 채찍 — 세션에 메시지 전송 | 제공 | 미제공 (창 앞으로 가져오기로 대체) |
| 지시 보내기, 자동 채찍 | 제공 | 미제공 |
| 작업 중지(Ctrl-C) | 제공 | 미제공 |
| 메모리 수치 | 활성 상태 보기와 동일(phys footprint) | resident size(근사치) |

App Store 판을 처음 실행하면 홈 폴더 접근 허용 창이 표시됩니다. **허용**을 선택하면 세션 제목과 상태가 표시되며, 이 설정은 저장되어 다시 묻지 않습니다.

### 2.3 Windows 및 Linux

Whiplash는 Electron으로 만든 별도 앱(소스는 `desktop/`)으로 Windows 10/11과 Linux에서도 동작합니다. 저장소의 GitHub Releases 페이지에서
내려받으며, 설치는 필요 없습니다.

| 플랫폼 | 파일 | 실행 방법 |
|---|---|---|
| Windows | `Whiplash-<버전>-win-x64.zip` | 아무 곳에나 풀고 `Whiplash.exe`를 실행합니다. 처음에는 SmartScreen 경고가 뜰 수 있습니다(추가 정보 → 실행). `.msi` 설치 파일이 함께 올라오는 경우도 있습니다. |
| Linux | `Whiplash-<버전>-linux-x64.AppImage` | `chmod +x` 후 실행합니다. 일부 배포판은 `libfuse2`가 필요하며, `.tar.gz`에는 일반 `whiplash` 실행 파일이 들어 있습니다. |

Windows·Linux 판에는 세션 감지, 상태 표시, 돌아다니기·목록 보기, 채찍, 간식, 확성기, 단축키, 트레이 메뉴가 있습니다.
채찍은 Claude Code의 명명 파이프(Windows) 또는 유닉스 소켓(Linux)으로 프롬프트를 전달하며, macOS와 같은 방식입니다.
제공되지 않는 기능: 당근밭과 남은 쿼터, 자동 채찍, 몸으로 때리기, iPhone / Watch 리모트, 입력 중 숨기기.
설정은 `%APPDATA%\Whiplash`(Windows) 또는 `~/.config/whiplash`(Linux)에 저장됩니다. 플랫폼별 주의 사항(Wayland, 트레이, WSL)은 `desktop/README.md`를 참고하세요.

## 3. 시작하기

처음 실행하면 환영 창이 한 번 열립니다. 기본 조작법 세 가지와 함께 다음 두 항목을 선택할 수 있으며, 나중에 **Settings ▸**에서 바꿀 수 있습니다.

| 항목 | 내용 |
|---|---|
| 남은 쿼터 보기 | 남은 쿼터를 당근으로 표시합니다. 켜면 macOS 키체인 허용 창이 한 번 뜹니다(5.4 참고). 직접 배포판에만 있습니다. |
| 로그인할 때 열기 | 로그인 항목으로 등록합니다. |

App Store 판은 이 창에서 **홈 폴더 허용…** 버튼으로 세션 정보 읽기를 허용합니다. 그 밖의 시스템 권한은 어느 판에서도 필요하지 않습니다.

이후 Whiplash는 자동으로 다음을 수행합니다.

- 에이전트 프로세스 탐지(2초 간격, 창이 가려져 있으면 15초 간격)
- Claude Code 세션 파일 읽기(제목, 작업 상태, 비용 누계)
- 메뉴 막대 아이콘 및 Dock 아이콘 표시
- 전역 단축키 등록

기본 보기 모드는 **풀어놓기**(캐릭터가 화면을 돌아다님)입니다. 목록 형태로 보려면 메뉴 막대 아이콘 → **채찍질 창으로 보기**를 선택하거나 ⌃⌥A를 누릅니다.

## 4. 화면 구성

### 4.1 채찍질 창 (목록 보기)

세션 목록과 자원 사용량을 보여 주는 창입니다. 테두리가 없으며 드래그하여 옮길 수 있습니다.

| 영역 | 내용 |
|---|---|
| 신호등 버튼 | 빨강: Whiplash 종료 (⌥ 누르고 클릭하면 숨기기만) / 노랑: 작게 보기 전환 / 초록: 풀어놓기 전환 |
| 헤더 | 세션 수, 작업 중 수, 응답 대기 수, 과부하 수, 자동 채찍 종료 시각 |
| CPU·메모리 막대 | 색상 = 에이전트, 회색 = 다른 앱, 빈 칸 = 여유 |
| 세션 행 | 캐릭터, 세션 제목, 프로젝트 폴더, 누적 비용, 변경 줄 수, 현재 작업, CPU·메모리 |
| 하단 | 에이전트 데이터 폴더 용량, 디스크 여유 공간, Whiplash 자체 자원 사용량 |

창을 두 번 클릭하면 **작게 보기**(캐릭터와 막대만 표시, 기본값)와 전체 목록을 오갑니다. 작게 보기에서는 한 줄에 10마리까지 놓이고 넘치면 다음 줄로 내려가며, 마리 수는 **Settings ▸ 한 줄에 몇 마리**에서 5·8·10·15·20 중 고를 수 있습니다.

### 4.2 풀어놓기 (화면 돌아다니기)

각 세션이 독립된 투명 창의 캐릭터로 표시되어 화면을 이동합니다.

- 작업 중인 세션은 도구를 들고 이동하며, 다른 앱 창의 상단 가장자리를 따라 걷기도 합니다.
- 유휴 세션은 제자리에서 대기합니다.
- 사용자의 응답이 필요한 세션은 머리 위에 말풍선 배지(`!` `?` `✋`)를 표시하고 주기적으로 뜁니다.
- 캐릭터끼리 겹치지 않도록 자동으로 간격을 유지합니다.
- 캐릭터는 드래그하여 옮길 수 있으며, 두 번 클릭하면 해당 세션을 실행 중인 앱(Claude 앱 또는 터미널)을 앞으로 가져옵니다.
- 마우스를 빠르게 움직이거나 타자를 치는 상태가 약 3초 이어지면 캐릭터들이 사라지고, 8초 동안 조용하면 다시 나타납니다(**Settings ▸ 일할 때 알아서 숨기**, 기본 켜짐). 캐릭터 위에 포인터가 있거나 당근밭에 있을 때는 숨지 않습니다. 키 입력은 내용이 아니라 마지막 입력 시각만 확인하며 별도 권한이 필요 없습니다.

**작게 풀어놓기**를 켜면 이름표 없이 작은 캐릭터만 표시됩니다.

### 4.3 당근밭

**당근밭에 박아두기**를 켜면 화면 한쪽에 당근밭 창이 생기고 모든 캐릭터가 걸어 들어와 각자 자기 자리에 앉습니다. 창은 드래그하여 옮길 수 있으며, **뽑아주기** 버튼으로 해제합니다. 당근밭에서는 캐릭터가 항상 작은 크기로 표시됩니다.

당근밭의 규칙

| 항목 | 규칙 |
|---|---|
| 당근 수 | 항상 10개 (5칸 × 2줄). 당근 1개 = 5시간 쿼터의 10% |
| 남은 당근 | ⌈10 × 남은 쿼터 비율⌉. 예: 75% 사용 → 3개 |
| 뽑히는 순서 | 오른쪽 끝부터 |
| 자리 배정 | 캐릭터는 왼쪽 당근부터 한 마리씩 앉음. 11마리째부터는 당근 없는 셋째 줄 |
| 굶는 중 | 자기 자리의 당근이 뽑힌 캐릭터에는 🥕✕ 표시. 머리글에 「n마리 굶는 중」 |
| 뽑아먹기 | 사용량 조회(5분마다)로 남은 당근이 줄면 그 자리의 캐릭터가 뛰어오르며 소리가 남 |
| 파업 | 당근 0개(쿼터 소진)이면 Claude 캐릭터 전원이 파업 (5.4 참고) |

**남은 쿼터 보기**(설정)를 켜지 않으면 당근 10개가 모두 남아 있는 장식으로만 표시됩니다.

## 5. 상태 표시

### 5.1 현재 작업

Claude Code 세션은 대화 기록을 바탕으로 현재 작업을 표시합니다.

| 표시 | 의미 | 캐릭터가 든 도구 |
|---|---|---|
| 읽는 중 · 파일명 | 파일 읽기 | 책 |
| 고치는 중 · 파일명 | 파일 편집·쓰기 | 연필 |
| 실행 중 · 설명 | 셸 명령 실행 | 망치 |
| 찾는 중 · 패턴 | 검색 | 돋보기 |
| 부하 시키는 중 | 하위 에이전트 실행 | 채찍 |
| 검색 중 / 웹 읽는 중 | 웹 검색·조회 | 지구본 |
| 생각하는 중 | 모델 추론 | 생각 풍선 |
| 답하는 중 | 응답 작성 | 말풍선 |

### 5.2 대기 상태

유휴 세션은 멈춘 이유와 경과 시간을 표시합니다. 응답이 필요한 상태는 노란색으로 강조됩니다.

| 표시 | 의미 |
|---|---|
| 답 기다리는 중 | 응답을 마치고 사용자 입력을 기다림 |
| 물어보고 기다림 | 질문 또는 계획 승인 대기 |
| 허락 기다리는 중 | 도구 실행 허가 대기 |
| 쉬는 중 | 유휴 |

### 5.3 과부하

세션이 CPU 1.5코어 이상 또는 메모리 2GB(또는 전체의 10%) 이상을 사용하면 행과 막대가 빨간색으로 바뀌고 캐릭터 머리 위에 증기가 표시됩니다. 헤더에 과부하 세션 수가 집계됩니다.

### 5.4 남은 쿼터 (🥕 당근)

**Settings ▸ 남은 쿼터 보기**를 켜면 Claude 구독의 남은 쿼터가 세션(5시간)·주간(모든 모델)·모델별 주간(Fable 등) 창으로 나뉘어 표시됩니다. 세션 창은 당근 10개로, 나머지는 막대로 그립니다. 쿼터가 차오를수록 당근이 줄고, 다 떨어지면 캐릭터들이 파업합니다.

조회에는 Claude Code가 로그인 시 키체인에 저장한 토큰을 사용합니다. 처음 켤 때 macOS가 **「로그인」 키체인 암호**를 묻는 창을 띄웁니다. 이것은 Claude 로그인이 아니라 Whiplash가 키체인 항목을 읽도록 허용하는 절차이며, 보통 Mac 로그인 비밀번호와 같습니다. **항상 허용**을 선택하면 다시 묻지 않습니다.

| 상황 | 대응 |
|---|---|
| 비밀번호가 맞지 않음 | 로그인 키체인 암호가 Mac 비밀번호와 달라진 경우입니다(비밀번호 변경 이력). 키체인 접근 앱 → 로그인 키체인 → 암호 변경으로 맞추거나, **허용 안 함**을 누르면 당근밭만 표시되지 않습니다. |
| 매번 다시 물음 | 서명이 바뀌면 다시 묻습니다. `build.sh`는 키체인에 Apple Development 인증서가 있으면 그걸로 서명해 빌드 간 서명을 고정합니다. 거부하면 그 실행 동안은 다시 묻지 않으며, **남은 쿼터 보기**를 껐다 켜면 다시 시도합니다. |
| 로그인 정보가 없다고 표시 | Claude Code에서 `/login`을 먼저 실행하십시오. |

`~/.claude/.credentials.json`이 있으면 키체인 대신 그 파일을 사용하며, 이 경우 암호 창이 뜨지 않습니다. 토큰은 요청에만 사용하고 저장하지 않습니다. 이 기능은 직접 다운로드판에서만 제공됩니다.

## 6. 세션 제어

### 6.1 지시 보내기

캐릭터 또는 세션 행을 드래그하지 않고 제자리에서 클릭하면 입력창이 나타납니다. 지시를 입력하고 ⏎를 누르면 해당 Claude Code 세션에 사용자 메시지로 전달됩니다. esc로 닫습니다.

- 유휴 세션은 즉시 처리합니다.
- 작업 중인 세션은 현재 턴이 끝난 뒤 처리합니다.
- 전송에 성공하면 캐릭터 테두리가 초록색으로 깜박이고 알림음이 재생됩니다.

입력창 위에는 그 세션의 맥락이 한두 줄 표시됩니다.

| 표시 | 내용 |
|---|---|
| ❓ 질문 + 선택지 버튼 | 세션이 질문(AskUserQuestion)이나 계획 승인을 기다리는 중. 버튼을 누르면 그 선택지가 그대로 전송됩니다. |
| 💬 마지막 말 | 세션이 마지막으로 한 말의 끝부분(보통 "…할까요?"). 유휴 세션이면 **응, 해 / 하지 마 / 계속해** 빠른 답 버튼이 함께 나타납니다. |

선택지와 마지막 말은 대화 기록에서 읽으며, 새 지시를 보내면 지워집니다.

### 6.2 채찍

유휴 또는 작업 중인 세션에 작업 재개를 지시하는 기능입니다.

**트랙패드**
- 맞을 때마다 트랙패드 햅틱이 울립니다(여러 마리면 연타).
- 두 손가락 튕김: 캐릭터 위에서 옆으로 휙 튕기면 채찍. 약 260px 이상 길게 튕기면 같은 줄에 선 캐릭터 전부. 마우스 휠은 해당 없음.

**여러 마리 한 번에**
- ⌃⌥G 「이리 와」로 캐릭터를 한 줄로 세운 뒤, 줄 위로 마우스를 한 번 빠르게(약 700px/s 이상) 휘두르면 지나간 캐릭터가 전부 동시에 채찍을 맞습니다. 소리는 마릿수만큼 겹쳐 재생됩니다.
- ⌃⌥⇧W 또는 메뉴 **쉬는 애 전부 채찍**: 유휴 세션 전부에 채찍 메시지를 보냅니다. 면역 세션은 제외됩니다.

**실행 방법**
1. 캐릭터 위에 포인터를 올리고 약 0.3초 머뭅니다. 캐릭터가 강조되고 포인터 옆에 채찍 표시가 나타납니다.
2. 포인터를 좌우(또는 위아래)로 빠르게 두 번 가로지릅니다(0.8초 이내). 줄 세워 둔 캐릭터는 위아래로 치는 것이 편합니다.

또는 ⌃⌥W(유휴 세션 임의 선택), 오른쪽 클릭 → **채찍 — 일감 골라 시키기**를 사용합니다.

**동작**
- Claude Code 세션: 세션에 짧은 메시지(기본값: `찰싹! (Whiplash) 하던 일 이어서 해. 끝났으면 다음 할 일 하나 골라서 해.`)를 전달합니다. 문구는 **오토 채찍질 → 채찍 프롬프트 편집…**에서 변경합니다.
- 메시지를 전달할 수 없는 에이전트(Codex, Gemini 등) 또는 일감을 지정한 경우: 같은 프로젝트 폴더에서 보조 에이전트를 읽기 전용 모드로 실행하여 일감을 처리합니다. 결과는 채찍질 창 하단에 표시되며 클릭하면 결과 문서가 열립니다.

**반응**
- 채찍을 맞으면 효과음과 함께 캐릭터가 반응합니다. 8초 이내에 반복하면 반응이 단계적으로 커집니다.
- 응답 대기 중인 세션을 8초 이내에 두 번 이상 때리면 메시지를 보내지 않고 거부 반응을 표시합니다.

**오작동 방지**
- 포인터가 머무르지 않고 스쳐 지나가는 경우에는 동작하지 않습니다.
- 설정 **⌥ 누른 채로만 채찍**을 켜면 ⌥ 키를 누른 상태에서만 동작합니다.
- 오른쪽 클릭 → **채찍 면역**을 켠 세션은 수동·자동 채찍 모두 제외되며 상태 줄에 🛡가 표시됩니다.

### 6.3 자동 채찍

지정한 시각까지 일정 간격으로 유휴 Claude Code 세션에 채찍 문구를 전달합니다.

- 메뉴 막대 아이콘 → **오토 채찍질** → 기간 선택(1시간, 3시간, 18시까지, 자정까지, 아침 9시까지)
- 간격: 3~60분(기본 10분)
- 허가 대기 중인 세션과 멈춘 지 1분 미만인 세션, 면역 세션은 제외됩니다.
- 활성 상태에서는 채찍질 창 헤더에 종료 시각이 표시되고, 종료 시 알림음이 재생됩니다.
- 앱을 다시 실행해도 종료 시각 전이면 계속됩니다.

> 자동 채찍은 설정한 기간 동안 에이전트의 토큰 사용을 유발합니다. 처음에는 짧은 기간과 긴 간격으로 시작하고, 파일 수정·명령 실행 허가 설정은 평소대로 유지할 것을 권장합니다.

### 6.4 기타 제어 (오른쪽 클릭 메뉴)

| 항목 | 동작 |
|---|---|
| 창 앞으로 | 세션을 실행 중인 앱을 활성화 |
| 폴더 열기 | 프로젝트 폴더를 Finder에서 열기 |
| 마지막 지시 복사 | 마지막 사용자 프롬프트를 클립보드로 복사 |
| 대화 기록 파일 열기 | 세션 기록(JSONL) 열기 |
| 하던 일 멈추기 (Ctrl-C) | 터미널 세션의 현재 작업 중단 (Claude 앱 세션은 제공되지 않음) |
| 채찍 면역 | 채찍 대상에서 제외 |

### 6.5 간식(칭찬)과 확성기

**간식**은 채찍의 반대입니다. 세션에 칭찬 프롬프트(기본: 「🥕 잘했어! (Whiplash) 지금처럼 계속해.」, Settings ▸ 간식 프롬프트 편집…)를 보내고 캐릭터가 「냠!」 하고 폴짝 뜁니다. 메시지를 못 받는 에이전트도 반응은 합니다.

| 방법 | 동작 |
|---|---|
| 쓰다듬기 | 캐릭터 위에 잠시 머문 뒤 **천천히**(초당 30~180px) 좌우로 세 번 쓸어 줍니다. 빠르면 채찍, 느리면 간식 |
| 오른쪽 클릭 → 🥕 간식 주기 | 그 세션에 간식 |
| ⌃⌥T / 메뉴 **일하는 애 전부 간식** | 일하는 세션 전부에 간식 |

**확성기**(⌃⌥B / 메뉴 **확성기 — 모두에게 같은 말…**)는 입력창을 "모두에게" 모드로 엽니다. 입력한 말이 Claude 세션 전부에 같은 내용으로 전달됩니다. 쉬는 세션은 바로, 일하는 세션은 턴이 끝난 뒤 읽습니다.

### 6.6 몸으로 때리기

**Settings ▸ 몸으로 때리기**에서 켭니다. 기본값은 전부 꺼짐입니다. 켠 동안에만 센서·카메라·마이크·네트워크를 사용하며, 영상과 소리는 저장하지 않습니다. 어느 방법이든 발동하면 **유휴 세션 전부에 한 번에** 채찍을 보냅니다(⌃⌥⇧W와 같음). 캐릭터들이 펄쩍 뛰고 소리가 겹쳐 울리며, 전 기능판에서는 각 세션에 채찍 프롬프트가 전달됩니다. 켜 둔 항목은 메뉴의 바로 아래 줄에 상태가 표시됩니다("듣는 중…", "카메라 접근 거부됨" 등).

| 방법 | 동작 | 필요한 것 |
|---|---|---|
| 에어팟 고개 휙 | 에어팟을 끼고 고개를 빠르게 돌리면(각속도 5.5 rad/s 이상) | macOS 14 이상, 모션 센서가 있는 에어팟(Pro·3세대·Max·Beats Fit Pro) |
| 카메라 손 휘두르기 | 카메라 앞에서 손을 0.35초 안에 화면 폭의 30% 이상 가로로 휘두르면 | 카메라 권한. 15fps로 손 관절만 추적 |
| 입으로 「화츅!」 | 조용하다가 50ms 안에 확 커지는 짧은 파열음 | 마이크 권한. 음량만 봄 |
| 아이폰·아이패드·애플워치 리모트 | 같은 Wi‑Fi의 Whiplash Remote 앱에서 폰을 휙 휘두르거나 손목을 튕기거나 버튼을 누르면 | 로컬 네트워크 권한. 앱은 `WhiplashRemote/` 참고 |

**에어팟 고개 휙.** 에어팟 안의 머리 움직임 센서(공간 음향이 쓰는 그 센서)를 맥이 읽습니다. 고개를 옆으로 휙 돌리면 6~10 rad/s쯤 나오고, 음악에 맞춰 끄덕이는 건 2 정도라 발동하지 않습니다. 쿨다운 1.5초. 그 순간 에어팟이 다른 기기에 연결돼 있으면 맥이 읽을 수 없고 상태 줄에 그렇게 표시됩니다. macOS 13에서는 이 항목이 숨겨집니다.

**카메라 손 휘두르기.** 켠 동안에만 카메라가 열립니다(초록 불이 계속 켜져 있습니다). Vision이 한 손의 손목을 추적해 0.35초 안에 화면 폭의 30%를 가로지르면 휘두른 것으로 봅니다. 영상은 메모리에서 분석하고 바로 버립니다. 쿨다운 2초. 팔 길이 정도 거리에서 카메라 앞에 손을 두면 가장 잘 됩니다.

**입으로 「화츅!」.** 마이크 음량을 계속 재다가 −34 dBFS 아래에서 −14 dBFS 위로 50ms 안에 뛰어오르면 채찍입니다. 말소리는 서서히 커지므로 발동하지 않습니다. 음량만 재고 소리 자체는 보지 않습니다. 쿨다운 1.5초.

**아이폰·아이패드·애플워치 리모트.** 별도 앱 Whiplash Remote이며 `WhiplashRemote/` 폴더에 있습니다. 준비 순서:

1. 맥에서 **Settings ▸ 몸으로 때리기 ▸ 아이폰·아이패드·애플워치 리모트 받기**를 켜고, macOS가 물으면 "로컬 네트워크"를 허용합니다. 그러면 Whiplash가 Wi‑Fi에 `_whiplash._udp`로 자신을 알립니다.
2. 아이폰에 Whiplash Remote를 설치합니다(워치 앱은 함께 설치됩니다). 아직 앱스토어에는 없고, `WhiplashRemote/`에서 Xcode로 빌드합니다(해당 README 참고).
3. 폰을 맥과 같은 Wi‑Fi에 두고 앱을 엽니다. Whiplash가 실행 중인 맥을 전부 찾아 모두에게 보냅니다.
4. 폰을 채찍처럼 휙 휘두르거나, 워치를 찬 손목을 튕기거나, 큰 버튼을 누릅니다. 폰은 휘두름을 감지한 순간 맥의 응답을 기다리지 않고 스스로 「화츅!」 소리를 내므로 반응이 즉각적입니다. 이어서 맥이 뭘 했는지("Whack! 3 whipped", "Nobody to whip")가 버튼 아래에 표시됩니다.
5. 폰에는 맥의 세션 목록이 상태(일하는 중·쉬는 중·내 차례·파업)와 함께 뜨고, 줄마다 채찍·간식 버튼과 「Treat all」이 있어 전부가 아니라 한 마리만 골라 때리거나 간식을 줄 수 있습니다.

휘두름은 사용자 가속도가 2.0g를 넘은 뒤 250ms 안에 손이 멈추는 것입니다. 걷기는 0.3g, 흔들기는 1.5g 정도라 발동하지 않습니다. 워치는 WatchConnectivity로 폰을 거쳐 보내므로 폰이 가까이에 켜져 있어야 합니다. 프로토콜은 47777 포트로 보내는 네 가지 텍스트 한 줄이라 Wi‑Fi에 있는 무엇이든 리모트가 될 수 있습니다. 단축어, 스트림덱, 다른 맥 등.

**조정과 알려진 한계.** 위 문턱값들은 센서 문서와 일반적인 값으로 정한 것이지 많은 사람에게 시험한 값이 아니므로, 머리·손·손목에 따라 조정이 필요할 수 있습니다. 각각 상수 하나입니다. `Motion.swift`(고개 휙), `HandCam.swift`(손 휘두르기), `MouthWhip.swift`(입), `WhiplashRemote/Shared/Flick.swift`(폰·워치). 앱스토어판에서는 몸으로 때리기가 세션 창을 앞으로 가져오고 반응만 재생하며, 채찍 프롬프트 전달은 직접 다운로드판에서만 됩니다(2.2 참고).

### 6.7 Claude 실행

Claude가 실행 중이지 않으면 **Claude (꺼짐)** 캐릭터가 표시됩니다. 채찍 동작으로 Claude 앱을 실행하거나, 오른쪽 클릭 → **터미널에서 claude 열기**에서 최근 프로젝트 폴더를 선택하여 터미널에서 Claude Code를 시작할 수 있습니다.

## 7. 메뉴 및 단축키

### 7.1 메뉴 막대 아이콘 / Dock 메뉴

메뉴 막대 아이콘과 Dock 아이콘(오른쪽 클릭)은 같은 메뉴를 보여 줍니다. 자주 쓰는 항목만 바로 보이고, 나머지는 **Settings ▸** 아래에 있습니다.

| 항목 | 동작 |
|---|---|
| 풀어놓기 — 화면 돌아다니기 / 채찍질 창으로 보기 / 모두 숨기기 | 보기 전환. 셋 중 하나에 체크 (⌃⌥A / ⌃⌥H) |
| 이리 와 | 모든 캐릭터를 포인터 위치로 이동 (⌃⌥G) |
| 당근밭에 박아두기 | 당근밭 모드 전환 (⌃⌥C) |
| 쉬는 애 아무나 채찍 | 유휴 세션 하나에 채찍 (⌃⌥W) |
| 오토 채찍질 ▸ | 기간·간격·채찍 문구 |
| Settings ▸ | 아래 표 |
| Whiplash 닫기 | 종료 |

**Settings ▸** 하위 항목

| 항목 | 동작 |
|---|---|
| 작게 풀어놓기 (이름표 없이) | 이름표 없는 소형 캐릭터 (⌃⌥M) |
| 캐릭터 뒤 물빛 칸 | 돌아다니는 캐릭터의 배경 타일 |
| 풀어놓을 때 채찍질 창도 보기 | 풀어놓기 중에도 목록 창 표시 (⌃⌥P) |
| 일할 때 알아서 숨기 | 마우스·타자가 바쁘면 캐릭터 숨김, 조용해지면 복귀 |
| 작게 보기 / 항상 맨 위에 | 채찍질 창 표시 설정 |
| ⌥ 누른 채로만 채찍 | 채찍 오작동 방지 |
| 남은 쿼터 보기 — 남은 쿼터 | 쿼터 조회 켜기 (처음 켤 때 macOS 키체인 허용 창이 뜸, 5.4 참고) |
| 채찍 프롬프트 편집… | 채찍질 때 세션에 보내는 글 |
| 보조 에이전트 일감 ▸ | 메시지를 못 받는 에이전트(Codex·Gemini)용 일감 목록, 결과 폴더 |
| 테마 ▸ / 언어 ▸ | 모양과 언어 |
| 단축키 편집… | `hotkeys.json` 열기. 저장하면 자동으로 다시 읽음 |
| Dock 에 아이콘 보이기 / 로그인할 때 열기 | 앱 설정 |

### 7.2 전역 단축키

어떤 앱이 활성화되어 있어도 동작합니다. 접근성 권한은 필요하지 않습니다.

| 단축키 | 동작 |
|---|---|
| ⌃⌥H | 모두 숨기기 / 보이기 |
| ⌃⌥A | 풀어놓기 / 채찍질 창 |
| ⌃⌥M | 작게 / 크게 |
| ⌃⌥C | 우리에 가두기 / 풀어주기 |
| ⌃⌥G | 이리 와 |
| ⌃⌥W | 유휴 세션 채찍 |
| ⌃⌥P | 풀어놓을 때 채찍질 창도 보기 |

변경: **Settings ▸ 단축키 편집…**으로 `hotkeys.json`을 열어 `"ctrl+alt+h"` 형식으로 수정하고 저장합니다. 다음에 메뉴를 열 때 자동으로 다시 읽습니다. 조합키는 ctrl, alt(option), cmd, shift를 지원하며, 값을 비우면 해당 단축키가 비활성화됩니다.

## 8. 설정 파일

모든 설정 파일은 `~/Library/Application Support/Whiplash/`에 저장됩니다.

| 파일 | 내용 |
|---|---|
| `whip-words.txt` | 채찍 시 세션에 전달하는 문구 |
| `whips.json` | 보조 에이전트 일감 목록 (`title`, `prompt`) |
| `hotkeys.json` | 전역 단축키 |
| `whips/` | 보조 에이전트 결과 문서(.md) 및 로그 |

창 위치, 보기 모드, 언어, 면역 세션 목록은 앱 기본 설정(`com.kade.whiplash`)에 저장됩니다.

## 9. 개인정보 및 보안

- Whiplash는 네트워크에 접속하지 않으며 어떤 데이터도 외부로 전송하지 않습니다.
- 프로세스 목록은 운영체제에서 읽기 전용으로 조회합니다.
- Claude Code 세션 정보는 `~/.claude/sessions`와 `~/.claude/projects`의 기록 파일 끝부분을 읽기 전용으로 조회합니다. 기록 파일은 크기가 바뀔 때만 다시 읽습니다.
- 세션에 메시지를 보낼 때는 Claude Code가 세션별로 제공하는 로컬 소켓과 인증 토큰(`~/.claude/sessions/*.key`)을 사용합니다. 토큰은 읽기만 하며 저장하거나 기록하지 않습니다.
- 보조 에이전트는 파일 수정·명령 실행 도구가 비활성화된 읽기 전용 모드로 실행되며, 15분이 지나면 자동 종료됩니다.

## 10. 문제 해결

| 증상 | 확인 사항 |
|---|---|
| 메뉴 막대 아이콘이 보이지 않음 | 노치가 있는 Mac에서 메뉴 막대가 가득 차면 항목이 숨겨질 수 있습니다. 다른 앱의 아이콘을 ⌘-드래그하여 제거하거나 Dock 아이콘을 사용하십시오. |
| 세션 제목이 표시되지 않음 | Claude Code 버전을 확인하십시오. App Store 판은 홈 폴더 접근을 허용해야 합니다(메뉴 → 홈 폴더 접근 허용…). |
| 채찍이 동작하지 않음 | 포인터를 캐릭터 위에 잠시 머문 뒤 좌우 또는 위아래로 두 번 가로지르십시오. 작업 중인 세션은 반응만 하고 메시지는 턴이 끝난 뒤 처리됩니다. ⌥ 전용 모드가 켜져 있는지 확인하십시오. |
| 메시지를 보낼 수 없음 | 입력창 하단의 오류 메시지를 확인하십시오. App Store 판에서는 제공되지 않습니다. |
| 캐릭터가 창을 가림 | 작게 풀어놓기, 우리에 가두기, 또는 채찍질 창으로 보기를 사용하십시오. |
| 전역 단축키가 충돌함 | 단축키 편집…에서 다른 조합으로 변경하십시오. |
| 설정이 반영되지 않음 (개발자) | 샌드박스 빌드를 한 번이라도 실행하면 `defaults` 명령이 컨테이너 설정을 가리킵니다. `~/Library/Preferences/com.kade.whiplash.plist` 경로를 직접 지정하십시오. |

## 11. 제거

1. 메뉴 막대 아이콘 → **Whiplash 닫기**로 종료합니다.
2. `/Applications/Whiplash.app`을 휴지통으로 옮깁니다.
3. 설정을 함께 제거하려면 `~/Library/Application Support/Whiplash/`와 `~/Library/Preferences/com.kade.whiplash.plist`를 삭제합니다.
