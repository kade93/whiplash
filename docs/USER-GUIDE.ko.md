# Whiplash 사용 설명서

버전 0.2 · macOS 13 이상 · Apple Silicon / Intel

Whiplash는 Mac에서 실행 중인 AI 코딩 에이전트(Claude Code, Codex, Cursor, Gemini CLI 등)를 모니터링하고 제어하는 데스크톱 유틸리티입니다. 각 에이전트 세션을 화면 위의 캐릭터로 표시하여 현재 작업, 대기 상태, 자원 사용량을 한눈에 파악할 수 있으며, 세션에 지시를 보내거나 작업을 재개시킬 수 있습니다.

---

## 1. 시스템 요구 사항

| 항목 | 요구 사항 |
|---|---|
| 운영체제 | macOS 13 Ventura 이상 |
| 프로세서 | Apple Silicon 또는 Intel |
| 지원 에이전트 | Claude Code(터미널·Claude 앱), Codex CLI/앱, Cursor, Gemini CLI, Antigravity, 기타(opencode, aider, goose 등) |
| 세션 정보 표시 | Claude Code 2.1 이상(세션 파일 `~/.claude/sessions` 생성 버전) |

세션 제목, 현재 작업, 대기 상태, 지시 보내기, 자동 채찍은 Claude Code 세션에서만 제공됩니다. 그 외 에이전트는 프로세스 단위의 CPU·메모리 정보만 표시됩니다.

## 2. 설치

### 2.1 직접 배포판 (전체 기능)

1. 배포된 `Whiplash.app`을 `/Applications`로 복사합니다.
2. 처음 실행 시 macOS가 확인을 요청하면 **열기**를 선택합니다. (Developer ID로 서명·공증된 빌드는 추가 확인 없이 실행됩니다.)
3. 메뉴 막대 오른쪽에 Whiplash 아이콘이 나타나고 모니터링이 시작됩니다.

소스에서 빌드하려면 Xcode Command Line Tools가 필요합니다.

```bash
xcode-select --install
./build.sh --install
```

### 2.2 Mac App Store 판 (기능 제한)

App Store 판은 Apple의 앱 샌드박스 안에서 동작합니다. 다음 기능이 제한됩니다.

| 기능 | 직접 배포판 | App Store 판 |
|---|---|---|
| 세션 모니터링, 상태 표시, 자원 사용량 | 제공 | 제공 (홈 폴더 접근 1회 허용 필요) |
| 화면 돌아다니기, 우리, 단축키, 메뉴 | 제공 | 제공 |
| 채찍 — 세션에 메시지 전송 | 제공 | 미제공 (창 앞으로 가져오기로 대체) |
| 지시 보내기, 자동 채찍 | 제공 | 미제공 |
| 작업 중지(Ctrl-C) | 제공 | 미제공 |
| 메모리 수치 | 활성 상태 보기와 동일(phys footprint) | resident size(근사치) |

App Store 판을 처음 실행하면 홈 폴더 접근 허용 창이 표시됩니다. **허용**을 선택하면 세션 제목과 상태가 표시되며, 이 설정은 저장되어 다시 묻지 않습니다.

## 3. 시작하기

처음 실행하면 다음이 자동으로 동작합니다.

- 에이전트 프로세스 탐지(2초 간격, 창이 가려져 있으면 15초 간격)
- Claude Code 세션 파일 읽기(제목, 작업 상태, 비용 누계)
- 메뉴 막대 아이콘 및 Dock 아이콘 표시
- 전역 단축키 등록

기본 보기 모드는 **풀어놓기**(캐릭터가 화면을 돌아다님)입니다. 목록 형태로 보려면 메뉴 막대 아이콘 → **채찍질 창으로 보기**를 선택하거나 ⌃⌥A를 누릅니다.

## 4. 화면 구성

### 4.1 채찍질 창 (목록 보기)

세션 목록과 자원 사용량을 보여 주는 창입니다. 테두리가 없으며 드래그하여 옮길 수 있습니다.

| 영역 | 내용 |
|---|---|
| 신호등 버튼 | 빨강: 닫기 / 노랑: 작게 보기 전환 / 초록: 풀어놓기 전환 |
| 헤더 | 세션 수, 작업 중 수, 응답 대기 수, 과부하 수, 자동 채찍 종료 시각 |
| CPU·메모리 막대 | 색상 = 에이전트, 회색 = 다른 앱, 빈 칸 = 여유 |
| 세션 행 | 캐릭터, 세션 제목, 프로젝트 폴더, 누적 비용, 변경 줄 수, 현재 작업, CPU·메모리 |
| 하단 | 에이전트 데이터 폴더 용량, 디스크 여유 공간, Whiplash 자체 자원 사용량 |

창을 두 번 클릭하면 **작게 보기**(캐릭터와 막대만 표시)로 전환됩니다.

### 4.2 풀어놓기 (화면 돌아다니기)

각 세션이 독립된 투명 창의 캐릭터로 표시되어 화면을 이동합니다.

- 작업 중인 세션은 도구를 들고 이동하며, 다른 앱 창의 상단 가장자리를 따라 걷기도 합니다.
- 유휴 세션은 제자리에서 대기합니다.
- 사용자의 응답이 필요한 세션은 머리 위에 말풍선 배지(`!` `?` `✋`)를 표시하고 주기적으로 뜁니다.
- 캐릭터끼리 겹치지 않도록 자동으로 간격을 유지합니다.
- 캐릭터는 드래그하여 옮길 수 있으며, 두 번 클릭하면 해당 세션을 실행 중인 앱(Claude 앱 또는 터미널)을 앞으로 가져옵니다.

**작게 풀어놓기**를 켜면 이름표 없이 작은 캐릭터만 표시됩니다.

### 4.3 우리

**우리에 가두기**를 켜면 화면 한쪽에 울타리 창이 생기고 모든 캐릭터가 그 안으로 이동하여 그 영역 안에서만 움직입니다. 울타리는 드래그하여 옮길 수 있으며, **풀어주기** 버튼으로 해제합니다.

## 5. 상태 표시

### 5.1 현재 작업

Claude Code 세션은 대화 기록을 바탕으로 현재 작업을 표시합니다.

| 표시 | 의미 | 캐릭터가 든 도구 |
|---|---|---|
| 읽는 중 · 파일명 | 파일 읽기 | 책 |
| 고치는 중 · 파일명 | 파일 편집·쓰기 | 연필 |
| 실행 중 · 설명 | 셸 명령 실행 | 망치 |
| 찾는 중 · 패턴 | 검색 | 돋보기 |
| 부하 시키는 중 | 하위 에이전트 실행 | 채찍 |
| 검색 중 / 웹 읽는 중 | 웹 검색·조회 | 지구본 |
| 생각하는 중 | 모델 추론 | 생각 풍선 |
| 답하는 중 | 응답 작성 | 말풍선 |

### 5.2 대기 상태

유휴 세션은 멈춘 이유와 경과 시간을 표시합니다. 응답이 필요한 상태는 노란색으로 강조됩니다.

| 표시 | 의미 |
|---|---|
| 답 기다리는 중 | 응답을 마치고 사용자 입력을 기다림 |
| 물어보고 기다림 | 질문 또는 계획 승인 대기 |
| 허락 기다리는 중 | 도구 실행 허가 대기 |
| 쉬는 중 | 유휴 |

### 5.3 과부하

세션이 CPU 1.5코어 이상 또는 메모리 2GB(또는 전체의 10%) 이상을 사용하면 행과 막대가 빨간색으로 바뀌고 캐릭터 머리 위에 증기가 표시됩니다. 헤더에 과부하 세션 수가 집계됩니다.

## 6. 세션 제어

### 6.1 지시 보내기

캐릭터 또는 세션 행을 드래그하지 않고 제자리에서 클릭하면 입력창이 나타납니다. 지시를 입력하고 ⏎를 누르면 해당 Claude Code 세션에 사용자 메시지로 전달됩니다. esc로 닫습니다.

- 유휴 세션은 즉시 처리합니다.
- 작업 중인 세션은 현재 턴이 끝난 뒤 처리합니다.
- 전송에 성공하면 캐릭터 테두리가 초록색으로 깜박이고 알림음이 재생됩니다.

### 6.2 채찍

유휴 또는 작업 중인 세션에 작업 재개를 지시하는 기능입니다.

**실행 방법**
1. 캐릭터 위에 포인터를 올리고 약 0.3초 머뭅니다. 캐릭터가 강조되고 포인터 옆에 채찍 표시가 나타납니다.
2. 포인터를 좌우로 빠르게 세 번 가로지릅니다(1초 이내).

또는 ⌃⌥W(유휴 세션 임의 선택), 오른쪽 클릭 → **채찍 — 일감 골라 시키기**를 사용합니다.

**동작**
- Claude Code 세션: 세션에 짧은 메시지(기본값: `찰싹! (Whiplash) 하던 일 이어서 해. 끝났으면 다음 할 일 하나 골라서 해.`)를 전달합니다. 문구는 **오토 채찍질 → 채찍 문구 편집…**에서 변경합니다.
- 메시지를 전달할 수 없는 에이전트(Codex, Gemini 등) 또는 일감을 지정한 경우: 같은 프로젝트 폴더에서 보조 에이전트를 읽기 전용 모드로 실행하여 일감을 처리합니다. 결과는 채찍질 창 하단에 표시되며 클릭하면 결과 문서가 열립니다.

**반응**
- 채찍을 맞으면 효과음과 함께 캐릭터가 반응합니다. 8초 이내에 반복하면 반응이 단계적으로 커집니다.
- 응답 대기 중인 세션을 8초 이내에 두 번 이상 때리면 메시지를 보내지 않고 거부 반응을 표시합니다.

**오작동 방지**
- 포인터가 머무르지 않고 스쳐 지나가는 경우에는 동작하지 않습니다.
- 설정 **⌥ 누른 채로만 채찍**을 켜면 ⌥ 키를 누른 상태에서만 동작합니다.
- 오른쪽 클릭 → **채찍 면역**을 켠 세션은 수동·자동 채찍 모두 제외되며 상태 줄에 🛡가 표시됩니다.

### 6.3 자동 채찍

지정한 시각까지 일정 간격으로 유휴 Claude Code 세션에 채찍 문구를 전달합니다.

- 메뉴 막대 아이콘 → **오토 채찍질** → 기간 선택(1시간, 3시간, 18시까지, 자정까지, 아침 9시까지)
- 간격: 3~60분(기본 10분)
- 허가 대기 중인 세션과 멈춘 지 1분 미만인 세션, 면역 세션은 제외됩니다.
- 활성 상태에서는 채찍질 창 헤더에 종료 시각이 표시되고, 종료 시 알림음이 재생됩니다.
- 앱을 다시 실행해도 종료 시각 전이면 계속됩니다.

> 자동 채찍은 설정한 기간 동안 에이전트의 토큰 사용을 유발합니다. 처음에는 짧은 기간과 긴 간격으로 시작하고, 파일 수정·명령 실행 허가 설정은 평소대로 유지할 것을 권장합니다.

### 6.4 기타 제어 (오른쪽 클릭 메뉴)

| 항목 | 동작 |
|---|---|
| 창 앞으로 | 세션을 실행 중인 앱을 활성화 |
| 폴더 열기 | 프로젝트 폴더를 Finder에서 열기 |
| 마지막 지시 복사 | 마지막 사용자 프롬프트를 클립보드로 복사 |
| 대화 기록 파일 열기 | 세션 기록(JSONL) 열기 |
| 하던 일 멈추기 (Ctrl-C) | 터미널 세션의 현재 작업 중단 (Claude 앱 세션은 제공되지 않음) |
| 채찍 면역 | 채찍 대상에서 제외 |

### 6.5 Claude 실행

Claude가 실행 중이지 않으면 **Claude (꺼짐)** 캐릭터가 표시됩니다. 채찍 동작으로 Claude 앱을 실행하거나, 오른쪽 클릭 → **터미널에서 claude 열기**에서 최근 프로젝트 폴더를 선택하여 터미널에서 Claude Code를 시작할 수 있습니다.

## 7. 메뉴 및 단축키

### 7.1 메뉴 막대 아이콘 / Dock 메뉴

| 항목 | 동작 |
|---|---|
| 모두 숨기기 | 모든 창과 캐릭터 숨김 (⌃⌥H) |
| 풀어놓기 — 화면 돌아다니기 | 풀어놓기 모드 전환 (⌃⌥A) |
| 작게 풀어놓기 | 이름표 없는 소형 캐릭터 (⌃⌥M) |
| 우리에 가두기 | 우리 모드 전환 (⌃⌥C) |
| 이리 와 | 모든 캐릭터를 포인터 위치로 이동 (⌃⌥G) |
| 쉬는 애 아무나 채찍 | 유휴 세션 하나에 채찍 (⌃⌥W) |
| 오토 채찍질 | 자동 채찍 기간·간격·문구 |
| 풀어놓을 때 채찍질 창도 보기 | 풀어놓기 중에도 목록 창 표시 (⌃⌥P) |
| Dock 에 아이콘 보이기 | Dock 아이콘 표시 여부 |
| 언어 | 한국어 / English / 日本語 |
| ⌥ 누른 채로만 채찍 | 채찍 오작동 방지 |
| 캐릭터 뒤 물빛 칸 | 돌아다니는 캐릭터의 배경 타일 표시 |
| 채찍질 창으로 보기 / 작게 보기 / 항상 맨 위에 / 로그인할 때 열기 | 창 표시 설정 |
| 채찍 일감 편집… / 채찍 결과 폴더 열기 | 보조 에이전트 일감 설정 |
| 단축키 편집… / 단축키 다시 읽기 | 전역 단축키 설정 |

### 7.2 전역 단축키

어떤 앱이 활성화되어 있어도 동작합니다. 접근성 권한은 필요하지 않습니다.

| 단축키 | 동작 |
|---|---|
| ⌃⌥H | 모두 숨기기 / 보이기 |
| ⌃⌥A | 풀어놓기 / 채찍질 창 |
| ⌃⌥M | 작게 / 크게 |
| ⌃⌥C | 우리에 가두기 / 풀어주기 |
| ⌃⌥G | 이리 와 |
| ⌃⌥W | 유휴 세션 채찍 |
| ⌃⌥P | 풀어놓을 때 채찍질 창도 보기 |

변경: **단축키 편집…**으로 `hotkeys.json`을 열어 `"ctrl+alt+h"` 형식으로 수정한 뒤 **단축키 다시 읽기**를 선택합니다. 조합키는 ctrl, alt(option), cmd, shift를 지원하며, 값을 비우면 해당 단축키가 비활성화됩니다.

## 8. 설정 파일

모든 설정 파일은 `~/Library/Application Support/Whiplash/`에 저장됩니다.

| 파일 | 내용 |
|---|---|
| `whip-words.txt` | 채찍 시 세션에 전달하는 문구 |
| `whips.json` | 보조 에이전트 일감 목록 (`title`, `prompt`) |
| `hotkeys.json` | 전역 단축키 |
| `whips/` | 보조 에이전트 결과 문서(.md) 및 로그 |

창 위치, 보기 모드, 언어, 면역 세션 목록은 앱 기본 설정(`kr.urbanism.whiplash`)에 저장됩니다.

## 9. 개인정보 및 보안

- Whiplash는 네트워크에 접속하지 않으며 어떤 데이터도 외부로 전송하지 않습니다.
- 프로세스 목록은 운영체제에서 읽기 전용으로 조회합니다.
- Claude Code 세션 정보는 `~/.claude/sessions`와 `~/.claude/projects`의 기록 파일 끝부분을 읽기 전용으로 조회합니다. 기록 파일은 크기가 바뀔 때만 다시 읽습니다.
- 세션에 메시지를 보낼 때는 Claude Code가 세션별로 제공하는 로컬 소켓과 인증 토큰(`~/.claude/sessions/*.key`)을 사용합니다. 토큰은 읽기만 하며 저장하거나 기록하지 않습니다.
- 보조 에이전트는 파일 수정·명령 실행 도구가 비활성화된 읽기 전용 모드로 실행되며, 15분이 지나면 자동 종료됩니다.

## 10. 문제 해결

| 증상 | 확인 사항 |
|---|---|
| 메뉴 막대 아이콘이 보이지 않음 | 노치가 있는 Mac에서 메뉴 막대가 가득 차면 항목이 숨겨질 수 있습니다. 다른 앱의 아이콘을 ⌘-드래그하여 제거하거나 Dock 아이콘을 사용하십시오. |
| 세션 제목이 표시되지 않음 | Claude Code 버전을 확인하십시오. App Store 판은 홈 폴더 접근을 허용해야 합니다(메뉴 → 홈 폴더 접근 허용…). |
| 채찍이 동작하지 않음 | 포인터를 캐릭터 위에 잠시 머문 뒤 좌우로 세 번 가로지르십시오. 작업 중인 세션은 반응만 하고 메시지는 턴이 끝난 뒤 처리됩니다. ⌥ 전용 모드가 켜져 있는지 확인하십시오. |
| 메시지를 보낼 수 없음 | 입력창 하단의 오류 메시지를 확인하십시오. App Store 판에서는 제공되지 않습니다. |
| 캐릭터가 창을 가림 | 작게 풀어놓기, 우리에 가두기, 또는 채찍질 창으로 보기를 사용하십시오. |
| 전역 단축키가 충돌함 | 단축키 편집…에서 다른 조합으로 변경하십시오. |
| 설정이 반영되지 않음 (개발자) | 샌드박스 빌드를 한 번이라도 실행하면 `defaults` 명령이 컨테이너 설정을 가리킵니다. `~/Library/Preferences/kr.urbanism.whiplash.plist` 경로를 직접 지정하십시오. |

## 11. 제거

1. 메뉴 막대 아이콘 → **Whiplash 닫기**로 종료합니다.
2. `/Applications/Whiplash.app`을 휴지통으로 옮깁니다.
3. 설정을 함께 제거하려면 `~/Library/Application Support/Whiplash/`와 `~/Library/Preferences/kr.urbanism.whiplash.plist`를 삭제합니다.
