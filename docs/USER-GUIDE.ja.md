# Whiplash ユーザーガイド

バージョン 0.2 · macOS 13 以降 · Apple Silicon / Intel

Whiplash は、Mac 上で動作する AI コーディングエージェント（Claude Code、Codex、Cursor、Gemini CLI など）を監視・操作するデスクトップユーティリティです。各エージェントのセッションを画面上のキャラクターとして表示し、現在の作業、待機状態、CPU・メモリ使用量をひと目で把握できます。セッションへ指示を送ったり、作業を再開させたりすることもできます。

---

## 1. 動作環境

| 項目 | 要件 |
|---|---|
| OS | macOS 13 Ventura 以降 · Windows 10/11 と Linux（x64）は 2.3 節の別版 |
| プロセッサ | Apple Silicon または Intel |
| 対応エージェント | Claude Code（ターミナル・Claude アプリ）、Codex CLI/アプリ、Cursor、Gemini CLI、Antigravity、その他（opencode、aider、goose） |
| セッション詳細 | Claude Code 2.1 以降（`~/.claude/sessions` を書き出すバージョン） |

セッション名、現在の作業、待機状態、指示送信、オート鞭は Claude Code セッションのみ対応です。その他のエージェントはプロセス単位の CPU・メモリのみ表示します。

## 2. インストール

### 2.1 直接配布版（全機能）

1. 配布された `Whiplash.app` を `/Applications` にコピーします。
2. 初回起動時に macOS が確認を求めたら **開く** を選びます。（Developer ID で署名・公証済みのビルドは追加確認なしで開きます。）
3. メニューバー右側に Whiplash のアイコンが表示され、監視が始まります。

ソースからビルドするには Xcode Command Line Tools が必要です。

```bash
xcode-select --install
./build.sh --install
```

### 2.2 Mac App Store 版（機能制限あり）

App Store 版は Apple のアプリサンドボックス内で動作します。以下の機能が異なります。

| 機能 | 直接配布版 | App Store 版 |
|---|---|---|
| セッション監視、状態表示、リソース使用量 | ○ | ○（初回にホームフォルダへのアクセス許可が必要） |
| 歩き回り、柵、ショートカット、メニュー | ○ | ○ |
| 鞭 — セッションへメッセージ送信 | ○ | ×（ウィンドウを前面に出す動作に置き換え） |
| 指示送信、オート鞭 | ○ | × |
| 作業の中断（Ctrl-C） | ○ | × |
| メモリ値 | アクティビティモニタと同じ（phys footprint） | resident size（概算） |

App Store 版を初めて起動するとホームフォルダへのアクセス許可ダイアログが表示されます。**許可** を選ぶとセッション名と状態が表示され、設定は保存されます。

### 2.3 Windows と Linux

Whiplash は Electron で作られた別アプリ（ソースは `desktop/`）として Windows 10/11 と Linux でも動作します。リポジトリの GitHub Releases
ページからダウンロードしてください。インストールは不要です。

| プラットフォーム | ファイル | 実行方法 |
|---|---|---|
| Windows | `Whiplash-<バージョン>-win-x64.zip` | 任意の場所に展開して `Whiplash.exe` を起動します。初回は SmartScreen の警告が出ることがあります（詳細情報 → 実行）。`.msi` インストーラーが添付される場合もあります。 |
| Linux | `Whiplash-<バージョン>-linux-x64.AppImage` | `chmod +x` して実行します。一部のディストリビューションでは `libfuse2` が必要です。`.tar.gz` には通常の `whiplash` 実行ファイルが入っています。 |

Windows・Linux 版には、セッション検出、状態表示、歩き回り・リスト表示、鞭、おやつ、拡声器、ショートカット、トレイメニューがあります。
鞭は Claude Code の名前付きパイプ（Windows）または Unix ソケット（Linux）でプロンプトを届けます。macOS と同じ仕組みです。
提供されない機能：ニンジン畑と残りクォータ、オート鞭、体で鞭を打つ、iPhone / Watch リモート、入力中の非表示。
設定は `%APPDATA%\Whiplash`（Windows）または `~/.config/whiplash`（Linux）に保存されます。プラットフォーム別の注意点（Wayland、トレイ、WSL）は `desktop/README.md` を参照してください。

## 3. はじめに

初回起動時にウェルカムウィンドウが一度開きます。基本操作 3 つの説明とともに次の 2 項目を選べ、あとから **Settings ▸** で変更できます。

| 項目 | 内容 |
|---|---|
| 残りクォータを表示 | 残りクォータをニンジンで表示します。オンにすると macOS キーチェーンの確認が一度出ます（5.4 参照）。直接配布版のみ。 |
| ログイン時に開く | ログイン項目として登録します。 |

App Store 版ではこのウィンドウの **ホームフォルダを許可…** ボタンでセッション情報の読み取りを許可します。そのほかのシステム権限はどちらの版でも不要です。

その後 Whiplash は自動的に次を行います。

- エージェントプロセスの検出（2 秒ごと、ウィンドウが隠れている間は 15 秒ごと）
- Claude Code セッションファイルの読み取り（タイトル、作業状態、累計コスト）
- メニューバーアイコンと Dock アイコンの表示
- グローバルショートカットの登録

既定の表示モードは **放す**（キャラクターが画面を歩き回る）です。リスト表示にするにはメニューバーアイコン → **ウィンドウで表示** を選ぶか ⌃⌥A を押します。

## 4. 画面構成

### 4.1 Whiplash ウィンドウ（リスト表示）

セッション一覧とリソース使用量を表示する枠なしウィンドウです。ドラッグで移動できます。

| 領域 | 内容 |
|---|---|
| 信号機ボタン | 赤: Whiplash を終了（⌥+クリックで隠すだけ） / 黄: コンパクト表示 / 緑: 放す |
| ヘッダー | セッション数、作業中、あなたの番、過負荷、オート鞭の終了時刻 |
| CPU・メモリバー | 色 = エージェント、灰 = 他のアプリ、空 = 空き |
| セッション行 | キャラクター、セッション名、プロジェクトフォルダ、累計コスト、変更行数、現在の作業、CPU・メモリ |
| フッター | エージェントのデータフォルダ容量、ディスク空き容量、Whiplash 自身の使用量 |

ウィンドウをダブルクリックすると **コンパクト表示**（キャラクターとバーのみ、初期設定）と全体リストを切り替えます。コンパクト表示では 1 行に 10 匹まで並び、超えると次の行に折り返します。匹数は **Settings ▸ 1 行あたりの匹数** で 5・8・10・15・20 から選べます。

### 4.2 放す（画面を歩き回る）

各セッションが独立した透明ウィンドウのキャラクターとして画面を移動します。

- 作業中のセッションは道具を持って歩き、他のアプリウィンドウの上辺も歩きます。
- 休憩中のセッションはその場で待機します。
- 返答が必要なセッションは頭上にバッジ（`!` `?` `✋`）を表示し、定期的に跳ねます。
- キャラクター同士は重ならないように間隔を保ちます。
- ドラッグで移動できます。ダブルクリックでそのセッションを実行しているアプリ（Claude アプリまたはターミナル）を前面に出します。
- マウスを速く動かすかタイピングが約 3 秒続くとキャラクターが消え、8 秒静かになるとそろそろ出てきます（**Settings ▸ 忙しいときは隠れ、休むとそろそろ出てくる**、既定でオン）。その場にぱっと現れるのではなく、近い画面の端（左・右・下）の外から体を半分だけ出して少し様子をうかがい、数歩進んでは止まりながら元の場所へ戻ります。1 匹ずつ時間差で出てきます。鞭で打つ、呼び集める、ドラッグするとそろそろ歩きはすぐ終わります。ポインタがキャラクターの上にあるときやニンジン畑にいるときは隠れません。キー入力は内容ではなく最後の入力時刻だけを確認し、権限は不要です。

**小さく放す** をオンにすると、名札なしの小さなキャラクターだけを表示します。

### 4.3 ニンジン畑

**ニンジン畑に植える** をオンにすると画面の端にニンジン畑のウィンドウが現れ、すべてのキャラクターが歩いて入り、それぞれの席に座ります。ウィンドウはドラッグで移動でき、**畑から抜く** ボタンで解除します。畑の中ではキャラクターは常に小さく表示されます。

畑のルール

| 項目 | ルール |
|---|---|
| ニンジンの数 | 常に 10 本（5 × 2 列）。1 本 = 5 時間クォータの 10% |
| 残りのニンジン | ⌈10 × 残りクォータ比率⌉。例: 75% 使用 → 3 本 |
| 抜かれる順 | 右端から |
| 席 | キャラクターは左のニンジンから 1 匹ずつ座る。11 匹目以降はニンジンのない 3 列目 |
| 空腹 | 自分の席のニンジンが抜かれたキャラクターには 🥕✕。見出しに「n匹が空腹」 |
| 食べる | 使用量の確認（5 分ごと）でニンジンが減ると、その席のキャラクターが跳ねて音が鳴る |
| ストライキ | ニンジン 0 本（クォータ消費）で Claude のキャラクター全員がストライキ（5.4 参照） |

**残りクォータを表示**（設定）がオフのときは、10 本すべてが残った飾りとして表示されます。

## 5. 状態表示

### 5.1 現在の作業

Claude Code セッションは会話ログから現在の作業を表示します。

| 表示 | 意味 | 持っている道具 |
|---|---|---|
| 読んでいる · ファイル名 | ファイルの読み取り | 本 |
| 編集中 · ファイル名 | ファイルの編集・書き込み | 鉛筆 |
| 実行中 · 説明 | シェルコマンド | ハンマー |
| 検索中 · パターン | 検索 | 虫眼鏡 |
| 部下に任せ中 | サブエージェント実行 | 鞭 |
| ウェブ検索中 / ウェブを読んでいる | ウェブ検索・取得 | 地球儀 |
| 考え中 | モデルの推論 | 思考の吹き出し |
| 返答中 | 返答の作成 | 吹き出し |

### 5.2 待機状態

休憩中のセッションは止まった理由と経過時間を表示します。入力が必要な状態は黄色で強調されます。

| 表示 | 意味 |
|---|---|
| 返事待ち | 返答を終え、ユーザーの入力を待っている |
| 質問中 | 質問または計画の承認待ち |
| 許可待ち | ツール実行の許可待ち |
| 休憩中 | アイドル |

### 5.3 過負荷

セッションが CPU 1.5 コア以上、またはメモリ 2 GB（または全体の 10%）以上を使うと、行とバーが赤くなり、キャラクターの頭上に湯気が出ます。ヘッダーに過負荷セッション数が集計されます。

### 5.4 残りクォータ（🥕 ニンジン）

**Settings ▸ 残りクォータを表示** をオンにすると、Claude サブスクリプションの残りクォータがセッション（5 時間）・週間（全モデル）・モデル別週間（Fable など）の枠に分かれて表示されます。セッション枠はニンジン 10 本、ほかは棒グラフです。クォータが埋まるほどニンジンが減り、尽きるとキャラクターがストライキをします。

取得には Claude Code がログイン時にキーチェーンへ保存したトークンを使います。初回は macOS が **「ログイン」キーチェーンのパスワード** を求める確認を表示します。これは Claude のログインではなく、Whiplash にキーチェーン項目の読み取りを許可する手続きで、通常は Mac のログインパスワードと同じです。**常に許可** を選べば以後は聞かれません。

| 状況 | 対応 |
|---|---|
| パスワードが通らない | ログインキーチェーンのパスワードが Mac のパスワードと異なっています（パスワード変更後に起こります）。キーチェーンアクセス → ログイン → パスワードを変更 で合わせるか、**許可しない** を押せばニンジン畑だけが表示されません。 |
| 毎回聞かれる | 署名が変わると再度聞かれます。`build.sh` はキーチェーンに Apple Development 証明書があればそれで署名し、ビルド間で署名を固定します。拒否するとその起動中は聞かれず、**残りクォータを表示** を入れ直すと再試行します。 |
| ログイン情報がないと表示 | 先に Claude Code で `/login` を実行してください。 |

`~/.claude/.credentials.json` があればキーチェーンの代わりにそのファイルを使い、確認は表示されません。トークンは取得にのみ使い、保存しません。この機能は直接ダウンロード版のみで利用できます。

## 6. セッションの操作

### 6.1 指示を送る

キャラクターまたはセッション行をドラッグせずにその場でクリックすると入力欄が開きます。指示を入力して ⏎ を押すと、その Claude Code セッションにユーザーメッセージとして届きます。esc で閉じます。

- 休憩中のセッションはすぐに処理します。
- 作業中のセッションは現在のターンが終わってから読みます。
- 送信に成功するとキャラクターの枠が緑に光り、効果音が鳴ります。

入力欄の上にはそのセッションの文脈が 1〜2 行表示されます。

| 表示 | 内容 |
|---|---|
| ❓ 質問 + 選択肢ボタン | セッションが質問（AskUserQuestion）や計画の承認を待っている状態。ボタンを押すとその選択肢がそのまま送られます。 |
| 💬 最後の言葉 | セッションの最後の発言の末尾（たいてい「…しますか？」）。休憩中のセッションなら **うん、やって / やめて / 続けて** のクイック返信が表示されます。 |

選択肢と最後の言葉は会話記録から読み取り、新しい指示を送ると消えます。

### 6.2 鞭

休憩中または作業中のセッションに作業の継続を指示する機能です。

**トラックパッド**
- 鞭が当たるたびにトラックパッドのハプティクスが鳴ります（複数ならその回数分）。
- 二本指フリック：キャラクターの上で横にさっと弾くと鞭。約 260px 以上長く弾くと同じ列のキャラクター全員。マウスホイールは対象外。

**複数を一度に**
- ⌃⌥G（おいで）でキャラクターを一列に並べ、その列の上をポインタで一度速く（約 700px/s 以上）振ると、通過したキャラクター全員が同時に鞭を受けます。音は匹数分重ねて再生されます。
- ⌃⌥⇧W またはメニューの **休んでる子を全員鞭**：休憩中のセッション全員に鞭メッセージを送ります。免疫セッションは除きます。 作業中のセッションと許可待ちのセッションも除かれるので、忙しいセッションに「続けて」が積み上がりません。反応は全員同時ですが、メッセージは 1 セッションずつ 3 秒間隔で送られます。十数個のエージェントが同じ瞬間にターンを始めて Mac が重くなるのを防ぐためです。マウスで複数のキャラをまとめて振り抜いたときも同じ間隔になります。まとめて打つとき、補助エージェントは合計 1 つまでしか起動しません。

**操作**
1. キャラクターの上にポインタを置き、約 0.25 秒待ちます。キャラクターが強調され、ポインタの横に鞭が表示されます。
2. ポインタをキャラクターの上で左右に素早く 3 回往復させます（1 秒以内）。

または ⌃⌥W（休憩中のセッションをランダム選択）、右クリック → **鞭 — タスクを選んで任せる** を使います。

**動作**
- Claude Code セッション: 短いメッセージ（既定: `ピシッ! (Whiplash) やりかけの作業を続けて。終わってたら次の仕事を一つ選んでやって。`）を届けます。文句は **オート鞭 → 鞭プロンプトを編集…** で変更します。
- メッセージを届けられないエージェント（Codex、Gemini など）やタスクを選んだ場合: 同じプロジェクトフォルダで補助エージェントを読み取り専用で起動し、タスクを処理します。結果はウィンドウ下部に表示され、クリックで開きます。

**反応**
- 鞭を受けると効果音とともにキャラクターが反応します。8 秒以内に繰り返すと反応が段階的に大きくなります。
- 返答待ちのセッションを 8 秒以内に 2 回以上叩くと、メッセージを送らず拒否反応を示します。

**誤動作防止**
- ポインタが通り過ぎるだけでは動作しません。
- 設定 **⌥を押している時だけ鞭** をオンにすると、⌥ キーを押している間だけ動作します。
- 右クリック → **鞭の免疫** をオンにしたセッションは手動・自動の鞭から除外され、状態行に 🛡 が表示されます。

### 6.3 オート鞭

指定した時刻まで一定間隔で、休憩中の Claude Code セッションに鞭の文句を届けます。

- メニューバーアイコン → **オート鞭** → 期間を選択（1 時間、3 時間、18 時まで、深夜 0 時まで、朝 9 時まで）
- 間隔: 3〜60 分（既定 10 分）
- 許可待ちのセッション、止まってから 1 分未満のセッション、免疫のセッションは除外されます。
- 有効な間はウィンドウのヘッダーに終了時刻が表示され、終了時に効果音が鳴ります。
- アプリを再起動しても終了時刻前なら継続します。

> オート鞭は設定した期間中、エージェントのトークン消費を伴います。最初は短い期間と長い間隔から始め、ファイル編集・コマンド実行の許可設定は通常どおりにしておくことをおすすめします。

### 6.4 その他の操作（右クリックメニュー）

| 項目 | 動作 |
|---|---|
| ウィンドウを前へ | セッションを実行しているアプリを前面に |
| フォルダを開く | プロジェクトフォルダを Finder で開く |
| 最後の指示をコピー | 最後のユーザープロンプトをクリップボードへ |
| 会話ログを開く | セッションログ（JSONL）を開く |
| 作業を止める (Ctrl-C) | ターミナルセッションの作業を中断（Claude アプリのセッションでは非対応） |
| 鞭の免疫 | 鞭の対象から除外 |

### 6.5 おやつ（ほめる）と拡声器

**おやつ**は鞭の反対です。セッションにほめるプロンプト（既定：「🥕 よくやった！(Whiplash) この調子で続けて。」、Settings ▸ おやつプロンプトを編集…）を送り、キャラクターが「もぐ！」と跳ねます。メッセージを受け取れないエージェントも反応はします。

| 方法 | 動作 |
|---|---|
| なでる | キャラクターの上で少し止まってから **ゆっくり**（毎秒 30〜180px）左右に 3 回なでる。速いと鞭、遅いとおやつ |
| 右クリック → 🥕 おやつをあげる | そのセッションにおやつ |
| ⌃⌥T / メニュー **働いてる子を全員おやつ** | 働いているセッション全員におやつ |

**拡声器**（⌃⌥B / メニュー **拡声器 — 全員に同じ言葉…**）は入力欄を「全員へ」モードで開きます。入力した言葉が Claude セッション全部に同じ内容で届きます。休憩中はすぐ、作業中はターンの後に読みます。

### 6.6 体で鞭を打つ

**Settings ▸ 体で鞭を打つ** でオンにします。初期状態はすべてオフです。オンの間だけセンサー・カメラ・マイク・ネットワークを使い、録画・録音はしません。どの方法でも発動すると**休憩中のセッション全員に一度に**鞭を送ります（⌃⌥⇧W と同じ）。キャラクターが跳ね、音が重なって鳴り、フル機能版では各セッションに鞭プロンプトが届きます。オンにした項目はメニューのすぐ下の行に状態が表示されます（「監視中…」「カメラへのアクセスが拒否されました」など）。

| 方法 | 動作 | 必要なもの |
|---|---|---|
| AirPods で首をひょい | AirPods を着けて首を素早く回す（5.5 rad/s 以上） | macOS 14 以降、モーションセンサー付き AirPods（Pro・第3世代・Max・Beats Fit Pro） |
| カメラで手を振る | カメラの前で手を 0.35 秒以内に画面幅の 30% 以上横に振る | カメラの権限。15fps で手の関節だけ追跡 |
| 口で「ヒュッ！」 | 静かな状態から 50ms 以内に急に大きくなる短い破裂音 | マイクの権限。音量だけを見る |
| iPhone・iPad・Apple Watch リモート | 同じ Wi‑Fi の Whiplash Remote アプリで端末を振る、手首を弾く、ボタンを押す | ローカルネットワークの権限。アプリは `WhiplashRemote/` 参照 |

**AirPods で首をひょい。** AirPods 内の頭部モーションセンサー（空間オーディオが使うもの）を Mac が読みます。首を横にひょいと振ると 6〜10 rad/s ほど、音楽に合わせてうなずく程度は 2 前後なので発動しません。クールダウン 1.5 秒。そのとき AirPods が他の機器に接続されていると Mac は読めず、状態行にそう表示されます。macOS 13 ではこの項目は表示されません。

**カメラで手を振る。** オンの間だけカメラが開きます（緑のランプが点き続けます）。Vision が片手の手首を追跡し、0.35 秒以内に画面幅の 30% を横切れば「振った」と判定します。映像はメモリ上で解析してすぐ捨てます。クールダウン 2 秒。腕の長さくらいの距離でカメラの前に手を置くと最もよく反応します。

**口で「ヒュッ！」。** マイクの音量を測り続け、−34 dBFS 以下から −14 dBFS 以上へ 50ms 以内に跳ね上がると鞭です。話し声は徐々に大きくなるので発動しません。音量だけを測り、音声そのものは見ません。クールダウン 1.5 秒。

**iPhone・iPad・Apple Watch リモート。** 別アプリ Whiplash Remote で、`WhiplashRemote/` フォルダにあります。準備手順：

1. Mac で **Settings ▸ 体で鞭を打つ ▸ iPhone・iPad・Apple Watch リモートを受け付ける** をオンにし、macOS に聞かれたら「ローカルネットワーク」を許可します。Whiplash が Wi‑Fi 上に `_whiplash._udp` として自分を知らせます。
2. iPhone に Whiplash Remote をインストールします（Watch アプリも一緒に入ります）。まだ App Store にはなく、`WhiplashRemote/` から Xcode でビルドします（同フォルダの README 参照）。
3. iPhone を Mac と同じ Wi‑Fi に置いてアプリを開きます。Whiplash が動いている Mac をすべて見つけ、全部に送ります。
4. iPhone を鞭のように振る、Watch を着けた手首を弾く、または大きなボタンを押します。iPhone は振りを検知した瞬間、Mac の応答を待たずに自分で「ヒュッ！」と鳴らすので反応は即座です。続いて Mac が何をしたか（"Whack! 3 whipped"、"Nobody to whip"）がボタンの下に表示されます。
5. iPhone には Mac のセッション一覧が状態（作業中・休憩中・あなたの番・ストライキ）付きで表示され、行ごとに鞭とおやつのボタン、「Treat all」があるので、全員ではなく 1 体だけ選んで打ったりおやつをあげたりできます。

振りとは、ユーザー加速度が 2.0g を超えたあと 250ms 以内に手が止まることです。歩行は約 0.3g、シェイクは約 1.5g なので発動しません。Watch は WatchConnectivity で iPhone 経由で送るため、iPhone が近くで起きている必要があります。プロトコルはポート 47777 へのテキスト 1 行が 4 種類だけなので、Wi‑Fi 上のものは何でもリモートになれます。ショートカット、Stream Deck、別の Mac など。

**調整と既知の制限。** 上のしきい値はセンサーの資料と一般的な値から決めたもので、多人数で試した値ではありません。頭・手・手首によって調整が必要なことがあります。それぞれ定数ひとつです：`Motion.swift`（首）、`HandCam.swift`（手）、`MouthWhip.swift`（口）、`WhiplashRemote/Shared/Flick.swift`（iPhone・Watch）。App Store 版では体のトリガーはセッションのウィンドウを前面に出して反応を再生するだけで、鞭プロンプトの送信は直接ダウンロード版のみです（2.2 参照）。

### 6.7 Claude の起動

Claude が起動していないときは **Claude（オフ）** のキャラクターが表示されます。鞭で Claude アプリを起動するか、右クリック → **ターミナルで claude を開く** で最近のプロジェクトフォルダを選び、ターミナルで Claude Code を開始できます。

## 7. メニューとショートカット

### 7.1 メニューバーアイコン / Dock メニュー

メニューバーアイコンと Dock アイコン（右クリック）は同じメニューを表示します。よく使う項目だけが最上位にあり、それ以外は **Settings ▸** の下にあります。

| 項目 | 動作 |
|---|---|
| 放す — 画面を歩き回る / ウィンドウで表示 / すべて隠す | 表示の切替。3 つのうち 1 つにチェック（⌃⌥A / ⌃⌥H） |
| おいで | すべてのキャラクターをポインタ位置へ（⌃⌥G） |
| ニンジン畑に植える | ニンジン畑モードの切替（⌃⌥C） |
| 休んでる子を誰でも鞭 | 休憩中のセッション 1 つに鞭（⌃⌥W） |
| オート鞭 ▸ | 期間・間隔・文句 |
| Settings ▸ | 下表 |
| Whiplashを終了 | 終了 |

**Settings ▸** の項目

| 項目 | 動作 |
|---|---|
| 小さく放す（名札なし） | 名札なしの小さなキャラクター（⌃⌥M） |
| キャラの後ろに水色タイル | 歩き回るキャラクターの背景タイル |
| 放している間もリストを表示 | 放している間もリストウィンドウを表示（⌃⌥P） |
| 忙しいときは隠れ、休むとそろそろ出てくる | マウス・タイピングが忙しいとキャラクターを隠し、手を止めると画面の端からそろそろ戻ってくる |
| コンパクト表示 / 常に最前面 | ウィンドウ設定 |
| ⌥を押している時だけ鞭 | 誤動作防止 |
| 残りクォータを表示 — 残りクォータ | クォータ取得を有効化（初回は macOS キーチェーンの確認が出ます。5.4 参照） |
| 鞭プロンプトを編集… | 鞭を打つときにセッションへ送る文 |
| 補助エージェントのタスク ▸ | メッセージを受け取れないエージェント（Codex・Gemini）用のタスク一覧、結果フォルダ |
| テーマ ▸ / 言語 ▸ | 外観と言語 |
| ショートカットを編集… | `hotkeys.json` を開く。保存すると自動で再読込 |
| Dockにアイコンを表示 / ログイン時に開く | アプリ設定 |

### 7.2 グローバルショートカット

どのアプリが前面でも動作します。アクセシビリティ権限は不要です。

| ショートカット | 動作 |
|---|---|
| ⌃⌥H | すべて隠す / 表示 |
| ⌃⌥A | 放す / ウィンドウ |
| ⌃⌥M | 小 / 大 |
| ⌃⌥C | 柵に入れる / 放す |
| ⌃⌥G | おいで |
| ⌃⌥W | 休憩中のセッションに鞭 |
| ⌃⌥P | 放している間もリストを表示 |

変更: **Settings ▸ ショートカットを編集…** で `hotkeys.json` を開き、`"ctrl+alt+h"` の形式で書き換えて保存します。次にメニューを開いたときに自動で再読込されます。修飾キーは ctrl、alt（option）、cmd、shift。値を空にするとそのショートカットは無効になります。

## 8. 設定ファイル

すべての設定は `~/Library/Application Support/Whiplash/` に保存されます。

| ファイル | 内容 |
|---|---|
| `whip-words.txt` | 鞭で届けるメッセージ |
| `whips.json` | 補助エージェントのタスク（`title`、`prompt`） |
| `hotkeys.json` | グローバルショートカット |
| `whips/` | 補助エージェントの結果（.md）とログ |

ウィンドウ位置、表示モード、言語、免疫リストはアプリの環境設定（`com.kade.whiplash`）に保存されます。

## 9. プライバシーとセキュリティ

- Whiplash はネットワークに接続せず、データを外部に送信しません。
- プロセス一覧は OS から読み取り専用で取得します。
- Claude Code のセッション情報は `~/.claude/sessions` と `~/.claude/projects` のログ末尾を読み取り専用で参照します。ログはサイズが変わった時だけ再読込します。
- セッションへのメッセージ送信には Claude Code がセッションごとに用意するローカルソケットとトークン（`~/.claude/sessions/*.key`）を使います。トークンは読むだけで保存・記録しません。
- 補助エージェントはファイル編集・コマンド実行ツールを無効にした読み取り専用で実行し、15 分で自動終了します。

## 10. トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| メニューバーアイコンが見えない | ノッチ付き Mac ではメニューバーが満杯だと項目が隠れます。他のアプリのアイコンを ⌘-ドラッグで外すか、Dock アイコンを使ってください。 |
| セッション名が表示されない | Claude Code のバージョンを確認してください。App Store 版はホームフォルダへのアクセス許可が必要です（メニュー → ホームフォルダのアクセスを許可…）。 |
| 鞭が反応しない | ポインタをキャラクターの上で少し待ってから、左右に 3 回往復させてください。作業中のセッションは反応のみで、メッセージはターン終了後に読まれます。⌥ 専用モードがオンになっていないか確認してください。 |
| メッセージを送れない | 入力欄の下のエラーを確認してください。App Store 版では利用できません。 |
| キャラクターがウィンドウを隠す | 小さく放す、柵に入れる、またはウィンドウで表示を使ってください。 |
| ショートカットが衝突する | ショートカットを編集… で別の組み合わせに変更してください。 |

## 11. アンインストール

1. メニューバーアイコン → **Whiplash を終了** で終了します。
2. `/Applications/Whiplash.app` をゴミ箱に移動します。
3. 設定も削除する場合は `~/Library/Application Support/Whiplash/` と `~/Library/Preferences/com.kade.whiplash.plist` を削除します。
