### Show HN

**Title:** Show HN: Whiplash – your AI coding agents as desktop critters you can whip

> I run several Claude Code sessions at once and kept missing the moment one of them stopped to ask me something. Whiplash reads the local session files and the process list and draws each agent as a pixel critter: bouncing when it works, asleep when idle, with a yellow bubble when it needs me.
>
> The joke that turned out to be useful: swipe the pointer back and forth over an idle critter and it receives a "keep going, or pick the next task" prompt. Line them up and one sweep wakes all of them.
>
> Details that may interest people here:
> - The Mac app is plain Swift compiled with swiftc, no dependencies. The Windows and Linux build is Electron and shares the sprite data.
> - Messages go to Claude Code through the local socket it already opens for each session. Other agents (Codex, Cursor, Gemini CLI) are shown and measured but not typed into.
> - Nothing leaves the machine. No account, no telemetry.
> - It watches tool calls in the transcript tail and warns when an agent is about to stage a secrets file or publish something.
> - The Mac App Store build is sandboxed and can only watch and jump to sessions; the full version is a three-line build from source.
>
> It is silly on purpose. It has also changed how I work with a handful of agents running. Happy to answer questions about reading the session files or the socket protocol.

## Things not to say

- That it is made by, endorsed by or partnered with Anthropic, OpenAI, Anysphere or Google.
- That it is "on the Mac App Store" before the review is approved. Until then: "in review" or "coming to the Mac App Store".
- That the App Store edition sends prompts to agents. It watches, organises and jumps to sessions; sending needs the build from source.
- That the leak guard prevents leaks. It is a tripwire that warns; it can miss things.
